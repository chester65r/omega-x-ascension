ISOLATED WORKSPACE

Files and editor

SANDBOX

File browsing and editing have a separate server setting (OMEGA_ENABLE_COMPUTER_FILES) and require computer:read / computer:write permissions. Files are temporary and may be cleared when the sandbox container is recreated. Shell commands are a different capability and remain disabled by default; do not enable them on a shared or internet-facing deployment until per-job isolation is added.

Cloud session required. Choose List files after secure enrollment.

Requires computer:read and computer:write scopes.

AUTHORIZED EXECUTION

Computer terminal

POLICY CONTROLLED

Command execution requires OMEGA_ENABLE_COMPUTER_EXECUTION=true plus a token with computer:execute and runs:approve. Keep it off on multi-tenant or internet-facing systems; the current container is resource-limited but is not a hardened per-job VM.
