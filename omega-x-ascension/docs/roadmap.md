# Incremental Roadmap

1. **Core reasoning:** this release; add auth, durable LangGraph checkpoints, SSE streaming, evaluation harness.
2. **Memory:** working/episodic/semantic/long-term stores, retention, consolidation, deletion.
3. **Research/tools:** SearXNG, source provenance, prompt-injection boundaries, tool policy.
4. **Collaboration:** parallel specialists, debate budgets, deterministic judge rubric.
5. **Sandbox:** isolated runner service and approval workflow.
6. **Knowledge graph:** start with PostgreSQL edges; add Neo4j only after measured need.
7. **Voice/vision:** separate GPU workers and streaming media gateway.
8. **Self-improvement:** offline benchmarks, signed proposals, human-gated releases.
